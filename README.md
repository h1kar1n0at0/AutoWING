# AutoWING

**《偶像大师 闪耀色彩》** (enza 版) 自动化工具

![控制面板截图](docs/images/control-panel.png)

## 快速开始

1. **下载与解压**：下载最新版压缩包，解压到**不含中文**的路径。
2. **启动工具**：双击 `AutoWING.exe`，稍等片刻弹出控制面板。
3. **准备游戏窗口**：点击 **「重启浏览器(CDP)」**，工具会自动打开带调试端口的游戏标签页；或手动启动已开启 CDP 端口的浏览器进入游戏。
4. **配置核心参数**（关键）：
   - **策略选择**：挖矿选 `TE`；追求粉丝数选 `140` 或 `230`。
   - **主属性**：根据支援卡与育成偶像选择 `vo` / `da` / `vi` 等。
   - **执行次数**：运行几轮后自动停止（`0` = 无限）。
   - 其他选项（体力道具、倍率、约定处理等）按需调整，修改后**记得点击「保存」**。
5. **启动任务**：点击 **「▶ 启动」**，工具会自动连接并开始育成。需要停止时点击 **「■ 停止」**。

> 💡 全程后台运行，不干扰你使用电脑，但请保持游戏标签页激活在前台。详细设置说明见 [用户指南](docs/用户指南.md)。
